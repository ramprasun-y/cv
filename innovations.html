Developer tools and utilities built early in my career to solve real productivity gaps in MicroStrategy and ETL environments — before such capabilities existed off the shelf.

01
ETL Monitoring
ETL Monitor Tool

Monitors ETL backend processes and sends notifications when a batch completes successfully. Also watches for specific events — step failures and long-running steps — and delivers targeted alerts to process owners. Supports configurable mail groups per process and can run as a standalone command-line program. Combined with Windows Task Scheduler, it becomes a fully automated, lightweight ETL health monitor.

02
Schema Documentation
MSTR RLM Creator

The Reporting Logical Model (RLM) is the living standard document for MicroStrategy projects — capturing all incremental schema model changes across releases, shared between teams for requirements design and impact estimation. RLM Creator auto-generates the full MicroStrategy schema into a structured Visio file, organizing all project tables, objects, and their relationships across multiple pages — instantly and accurately.

03
SQL Analysis
MSTR SQL Documentation Tool

Extracts the SQL generated for every MicroStrategy report into an Excel sheet — because studying SQL is the most effective way to analyze report behavior. Goes further by comparing SQL against a previous version of the same report and highlighting exactly what changed. Answers prompts automatically and captures output. Invaluable for multi-release projects where schema changes needed to be tracked from release to release.

04
Prompt Debugging
MSTR Prompt SQL Extraction Tool

When complex prompts are used in MicroStrategy reports, there is no native way to inspect the SQL being generated against the database. This tool fills that gap — extracting the exact SQL produced by prompts and populating it into Excel for deep analysis. Essential for architects and developers debugging complex prompt logic, validating query efficiency, and ensuring correctness of results.

05
Object Versioning
MSTR Object Tracker

MicroStrategy has no native object versioning. If any object is modified, there is no built-in record of when or how. For large projects that use Object Migrations across releases, this is a critical gap. MSTR Object Tracker snapshots all project objects before modifications and can compare the project at any later point — clearly identifying every deleted, modified, and newly added object. Brought version-control discipline to MicroStrategy project governance long before it was a platform feature.
